# 原理图符号、PCB 封装与 3D 模型通用制作规范

版本：1.1　适用范围：不同器件、硬件项目及 EDA/CAD 软件中的器件库制作、整理与核验。

本文规定资料获取、原理图符号、PCB 封装、3D 模型及库关联的可复用流程。执行时读取目标项目的库结构、软件版本和绘图约定；具体料号、路径、文件格式及工具作为任务参数，不固定为某个工程。本文包含独立使用所需的符号规则；原理图页面整理属于另一项工作，可使用目标项目的原理图绘制规则，或本仓库独立的 circuit-schematic 技能。

## 1. 总体流程与交付物

**确定完整料号 → 收集资料 → 建立参数及引脚表 → 绘制符号 → 设计 PCB 封装 → 制作/校核 3D 模型 → 在软件中关联 → 验收后纳入工程库。**

| 对象 | 表达内容 | 必须对应的依据 | 交付格式 |
|---|---|---|---|
| 原理图符号 | 电气引脚、功能分组及连接关系 | 引脚表、功能说明、参考电路 | 目标 EDA 的原生符号库文件 |
| PCB 封装 | 焊盘、孔、装配外形、方向及间距 | 推荐焊盘图、机械尺寸及装配要求 | 目标 EDA 的原生封装库文件 |
| 3D 模型 | 器件实体外形、安装高度及机械配合 | 封装机械图、机械 CAD 或实物尺寸 | 目标软件支持的 3D 模型及可编辑源文件 |

原理图符号的引脚位置可按阅读要求安排。PCB 焊盘必须对应实际引脚位置。3D 模型中的引脚、外壳及安装面必须与 PCB 封装对齐。

每个器件应交付：资料来源、参数表、引脚映射表、符号、PCB 封装、3D 模型、可编辑模型源文件（自行建模时）、关联记录及验收截图。资料缺失的项目标记待确认，不以相似器件的尺寸补作已确认参数。

## 2. 从 datasheet 和公开资料获取参数

### 2.1 资料优先级

1. 器件厂家针对完整料号提供的 datasheet、封装图、推荐焊盘图、应用说明及机械 CAD。
2. 厂家官方资料库、参考设计及封装代号说明。
3. 授权分销商公开的厂家原始资料。
4. 公开器件库、社区模型及第三方 CAD：可用作起点，逐项与厂家资料核对。

资料冲突时先确认料号后缀、封装版本和图纸视角，记录差异；必要时向厂家确认。每份资料记录标题、发布者、版本/日期、链接、本地副本、页码及获取日期。公开模型同时记录作者、许可和修改情况。

### 2.2 参数记录表

| 类别 | 必须提取或确认的参数 |
|---|---|
| 器件身份 | 厂家、完整料号、订货后缀、封装代号、引脚数量 |
| 引脚 | 引脚号/球位、名称、电气类型、功能、NC/DNC/保留脚、裸露焊盘用途 |
| 电气分组 | 核心/模拟/数字电源、I/O Bank、电压范围、各类地及参考电路要求 |
| 封装外形 | 本体长宽高、引脚总跨度、离板高度、尺寸公差 |
| 焊接端子 | 间距、引脚/球尺寸、端子长度宽度、排布及缺球位置 |
| 推荐焊盘 | 铜焊盘尺寸、中心距、阻焊定义方式、钢网开窗和散热要求 |
| 插件与连接器 | 端子截面、孔径建议、安装脚、定位柱、板边关系、配合及插拔空间 |
| 图纸约定 | mm/inch、Top/Bottom View、Pin 1、坐标原点、引脚编号方向 |
| 3D 依据 | 安装面、最高点、插入深度、外壳/端子形状及机械公差 |

尺寸分别保留最小、典型和最大值；图纸未给出的值明确标为未提供。单位统一为 mm，同时保留原始单位以便复核。扫描图只用于辅助辨认，不能靠图片比例推定关键尺寸。

### 2.3 建立统一引脚映射表

每个真实端子一行，至少包含：`完整料号 / 原理图单元 / 引脚号 / 名称 / 电气类型 / PCB 焊盘号 / 端子坐标 / 备注 / 依据页码`。BGA 使用厂家球位编号，不连续补号；裸露焊盘按资料确认其编号和电气用途。

## 3. 按约定规则绘制原理图符号

### 3.1 引脚分区

引脚数量按完整器件不同物理引脚号统计，包含电源、地、NC 和散热焊盘。以下为本规范的默认绘图风格，来源于已确认的用户约定，并非行业强制标准。复用时可由目标项目明确的绘图要求覆盖；引脚正确性、尺寸依据和关联准确性仍必须满足。

| 引脚数 | 默认绘图约定 |
|---|---|
| 小于 48 | 优先复用目标项目已有且核验正确的符号，按功能清楚分组。 |
| 等于 48 | 电源放左下、地放右下；NC 放在信号与供电区域之间。 |
| 大于 48 | 信号按功能分组，NC、电源、地各自独立成单元；NC 位于信号与供电之间，电源左下、地右下。 |

- 无厂家定义的 NC 时，不制造虚构 NC 引脚或空单元。
- 未用 GPIO、控制或信号引脚属于信号单元，不能改成原生 NC。
- 同一芯片各单元共用一个位号，每个真实引脚出现一次，不重复、不遗漏。
- 电源按核心、模拟、数字、I/O Bank 等组别排列。同组连续，组间留空并注明组别；不能只按脚号混排。
- 地保留 AGND、DGND、VSS、EP/GND 等原有名称及电气含义；分组本身不代表不同地已连接。

### 3.2 图形、引脚和文字

- 信号单元在上、NC 居中、电源和地在下。同排单元顶部对齐，同列边界对齐；保留型号、标签和导线空间。
- 同类引脚统一朝向、长度和间距。网格以目标 EDA 的连接规则和已有库约定为准；可采用 1.27 mm 连接网格及 2.54 mm 引脚行距，作为可调整的绘图默认值。
- 数据总线按位序排列，差分正负脚相邻；地址、控制、时钟等功能之间留空。
- 位号在上、型号在下，字体、对齐方式和偏移统一；功能标题与引脚文字不得重叠。
- 引脚号、名称、电气类型和映射取自资料；排版不能改变其电气身份。
- DNC、保留脚及多功能脚按厂家说明处理，不能仅凭名称推断电气类型或连接方式。

### 3.3 符号验收

比较绘制前后的完整引脚清单；确认单元间没有重复脚、漏脚或错误电气类型。既有工程更新符号时，同步所有引用单元和导线，比较物理引脚连接集合，执行 ERC，并导出符号与受影响页面复检。

## 4. 按尺寸设计 PCB 封装

### 4.1 确定焊盘设计依据

优先采用厂家给出的 recommended land pattern。封装机械端子尺寸与 PCB 推荐焊盘尺寸分别记录，不能直接将端子轮廓作为焊盘。厂家未给焊盘图时，依据端子公差、贴装/焊接工艺及明确版本的封装设计规范计算，并记录计算输入与假设。

公开封装先核对完整封装代号、Pin 1、端子数量、间距、本体、裸露焊盘、孔及编号。名称类似或外形相似不足以判定兼容。结合厂家推荐与加工能力选择焊盘形状和阻焊方式，可参考 [KiCad SMD 焊盘约定](https://klc.kicad.org/footprint/f6/f6.3/)。

### 4.2 焊盘与编号

- 建立统一原点并注明方向；将底视图转换为板顶视图后，逐脚核对，防止镜像。
- 焊盘编号必须与符号引脚号一致；NC 若对应真实端子，PCB 上仍应保留该端子焊盘。
- QFN/QFP 核对端子宽长、间距、总跨度、裸露焊盘和 Pin 1。BGA 核对球阵列、缺球及字母数字方向。
- 同一电气端子的分割铜焊盘可共用同一编号；钢网分窗不增加电气引脚。导热过孔与电气焊盘的关系按实际设计明确记录。
- 插件孔依据引脚最大截面、成品孔要求及装配余量设计，区分 PTH 与 NPTH，核对孔铜、环宽及槽孔能力。
- 阻焊、钢网、裸露焊盘分窗及导热孔按厂家建议和板厂/贴装能力确定，不给所有器件套用同一固定余量。

### 4.3 图层与装配空间

| 图层/对象 | 要求 |
|---|---|
| Copper / Pad | 表达真实焊接连接和端子编号。 |
| Mask / Paste | 表达阻焊开窗与钢网设计，分别核对。 |
| F.Fab / B.Fab | 按机械资料绘制装配外形、方向与 Pin 1；统一位号、型号文字。 |
| F.SilkS / B.SilkS | 提供识别信息，避开焊盘和阻焊开窗，满足制造线宽和间距。 |
| F.CrtYd / B.CrtYd | 闭合装配边界，覆盖本体、端子及所需装配余量。 |
| Keepout / Mechanical | 按资料明确禁布、安装孔、板边和配合要求；插拔空间单独表达。 |

丝印和装配图采用统一的 Pin 1 标识。机械尺寸、公差与装配余量分开保存，可参考 [KiCad 封装库约定](https://klc.kicad.org/)。

### 4.4 PCB 封装验收

逐项测量焊盘/孔中心坐标、尺寸、间距、本体轮廓和 Pin 1；逐脚比较符号与焊盘编号。运行封装检查，在测试板或工程板检查 DRC；打印 1:1 视图或与实物叠合辅助验证。DRC 和打印比较均不能替代尺寸依据复核。

## 5. 根据机械资料制作 3D 模型

### 5.1 模型来源与建模

优先使用厂家提供的精确料号 STEP；公开 STEP 必须核对尺寸、版本、方向和许可。没有可用模型时，可在参数化 CAD 软件中按机械图绘制本体、端子、球、定位柱、安装脚、外壳及 Pin 1，并保留可编辑源文件。

默认以 mm 为建模单位，优先交付 STEP 实体模型；展示需要可附加其他模型格式。基本尺寸使用图纸典型值，机械干涉检查另外记录最大外形与公差包络。不得通过任意缩放外观模型修补错误的焊盘尺寸。

### 5.2 坐标和机械配合

- 明确模型原点、朝向及安装面；PCB 表面、封装原点与模型安装面建立对应关系。
- 核对本体长宽高、端子位置、离板高度、Pin 1 和焊盘编号方向。
- 自建 mm 模型优先以 1:1 比例关联；旋转和偏移参数明确记录。第三方模型先核对单位再转换。
- 连接器额外检查插口、板边、外壳、安装脚与插拔方向；保留配合空间。
- 分别查看顶部、底部、侧面和透视图，确认模型没有镜像、穿板、悬空或错位。

STEP 模型用于机械表达，焊盘编号和连接仍由符号及 PCB 封装核对。

## 6. 在目标软件中关联为可复用器件库

### 6.1 库结构与身份

先检查目标项目的现有库组织方式，沿用有效的库名、标识及目录约定。若没有既定结构，再分别组织符号、PCB 封装、3D 模型、来源资料和检查记录；路径由项目根目录或软件的库路径变量解析。

完整料号、封装后缀与库条目建立明确对应关系。通用符号可供多个料号复用，但每个实际器件必须有经过核验的封装及模型选择记录。共享封装需要确认机械、电气和装配兼容性。

### 6.2 通用关联流程

1. 在目标 EDA 中注册或导入符号库和 PCB 封装库，使其可检索。
2. 使用软件支持的标识或映射表，将器件符号关联到指定 PCB 封装。
3. 逐项核对符号引脚号与封装焊盘号；多单元芯片必须合并为同一物理器件。
4. 在 PCB 封装或器件条目的模型设置中关联 3D 文件，记录单位、偏移、旋转和比例。
5. 在测试项目或目标工程放置器件，完成原理图到 PCB 的同步，核对端子网络。
6. 打开 3D 视图检查实体对齐，再验证库随项目移动或按约定部署后仍能加载。

软件可能采用“符号 → PCB 封装 → 3D 模型”的关联链，也可能由统一器件条目分别引用三者。以目标软件实际的数据模型为准，保持引脚映射和器件身份可追溯。

### 6.3 KiCad 实现示例

此节只在目标软件为 KiCad 时适用，其他软件使用其对应的库注册、封装分配和模型设置功能。

- 符号库为 `.kicad_sym`；封装库为 `.pretty` 目录中的 `.kicad_mod`。
- 工程专用库分别登记在 `sym-lib-table` 和 `fp-lib-table`；符号的 `Footprint` 字段使用 `库名:封装名`。
- 在封装属性中关联 3D 模型，项目相对路径可使用 `${KIPRJMOD}`，例如 `${KIPRJMOD}/library/models/PartName.step`。该路径仅为示例。
- 更新 PCB 后核对网络，在 3D 查看器检查模型的安装面、方向及端子位置。

软件操作依据见 [KiCad 原理图编辑器文档](https://docs.kicad.org/9.0/en/eeschema/eeschema.html) 与 [KiCad PCB 编辑器文档](https://docs.kicad.org/9.0/en/pcbnew/pcbnew.html)。实际执行时核对所用版本。

### 6.4 更新与迁移

保存库文件后，按目标软件的机制同步已有实例；复查受影响导线、网络和模型定位。验证时使用副本或合适的测试工程，避免测试过程改变无关设计。归档必要的模型源文件、资料、路径配置及版本记录，使其他使用者能够复现。

## 7. 工程库验收与状态

| 验收项 | 通过条件 |
|---|---|
| 资料 | 完整料号、封装版本、来源和页码可追溯；关键参数无未说明缺口。 |
| 符号 | 引脚号/名称/类型正确；分区、排布和标识符合已选定的绘图约定。 |
| PCB 封装 | 编号、焊盘、孔及尺寸依据正确；图层和制造条件已核对。 |
| 3D | 尺寸、安装面、方向和端子对齐；最高点及机械空间已检查。 |
| 关联 | 符号到封装、封装到模型的链接均有效，工程移目录后可加载。 |
| 回归 | 既有连接无非预期变化，新增 ERC/DRC 问题已解决或明确记录。 |

状态分别记录为“资料待补”“绘制完成待核对”“验收通过”。符号、PCB 封装、3D 模型各自记录状态；某一项通过不能代替其余项通过。

### 单器件记录模板

- 完整料号 / 厂家 / 封装代号：
- datasheet 与封装图：版本、链接、本地文件、页码。
- 参数表与引脚映射表：
- 符号库标识 / PCB 封装库标识 / 3D 路径：
- 3D 来源或建模源文件 / 许可 / 偏移、旋转、比例：
- 与推荐图的差异及理由：
- 符号 / PCB 封装 / 3D / 关联的检查结果：
- 检查人 / 日期 / 文件版本 / 待确认项：

文档描述的是制作流程；某个器件或项目的实际完成状态必须由其交付文件和验收记录证明。
