# 分图页：对外接口与 ESD

适用于 USB、HDMI、Ethernet 及其他对外接口；完整设计进入绘制前须满足总标准的三项前置资料门槛；显式限定的局部任务遵循 SKILL.md 的范围规则。

## 功能与版面

- 页左为连接主控的总线接口，中间为控制器/收发器、选择器、隔离及信号处理，右侧为对外连接器；供电、配置和辅助电路成组放下方。
- 标出每一功能块和连接器完整料号；按实际功能决定是否需要转换、复用、隔离、电平匹配及电源保护。
- 差分线成对相邻，通道顺序一致；数据、控制、侧带、电源及屏蔽分别标识。连接器使用真实引脚编号，不以外观代替引脚图。

## ESD 器件与芯片连接

- 依据接口速率、电压范围、端口暴露情况、系统防护目标和芯片容限，核对保护器件的工作电压、钳位特性、电容、漏电及通道数；记录 datasheet 和参考设计。
- 在对应信号路径旁画出保护器件，逐通道标明被保护网络、地和供电；普通 TVS 为对参考节点的支路，不能误画成串联元件。带通道进出脚的器件按真实内部结构连接。
- 串联电阻、耦合电容、共模器件及选择器按厂家实际拓扑布线，避免旁路短接或丢失翻转控制。
- USB 分别核对数据、CC、VBUS 和屏蔽；HDMI 分别核对差分通道、DDC、HPD、CEC、电源及屏蔽。不同类型信号分别选择适合的防护方案。
- Ethernet 按 PHY、磁性器件及防护方案确认保护位置、中心抽头和地参考；机壳地与逻辑地的关系单独表达，不套用 USB 的直接保护拓扑。

## 检查与 PCB 交接

建立“主控/接口芯片脚 → 处理及保护通道 → 连接器脚”映射，检查极性、翻转、供电和参考节点。向 PCB 交接保护位置、回流、隔离间距和高速约束。一般 ESD 布局重视靠近放电入口及低电感路径；隔离接口按对应参考方案确定位置。[TI ESD 布局指南](https://www.ti.com/lit/an/slva680a/slva680a.pdf)、[TI Ethernet 防护参考设计](https://www.ti.com/lit/ug/tidues1a/tidues1a.pdf)。

原理图 ERC/网表及图片检查用于确认表达和连接，不能代替整机 ESD 测试或高速信号验证。
