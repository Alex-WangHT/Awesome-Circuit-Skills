# 可复用的原理图绘制设计规则

## 1. 总体原则

原理图应使阅读者清楚识别器件、参数、信号路径、电源域及跨页关系。先确认电路，再安排布局，再布线，最后整理标识并验证；排版过程中发现连线拥挤时回到布局步骤。

- 必须保证电气连接、引脚编号、符号与封装映射正确。
- 必须让真实连接、交叉、未用脚和可选器件有明确表达。
- 建议按功能分区，以左到右的主路径组织信号，以向上电源、向下地组织供电。
- 建议统一器件朝向、间距、文字格式和网络命名，使重复电路便于比较。

## 2. 开始绘图前：建立连接依据

以下门槛用于完整设计。用户明确限定仅排版、页内连接保持或局部检查时，按 SKILL.md 的范围规则执行，记录未检查项；不能因此宣称系统设计已完成。

### 2.1 绘制前置门槛

**开始绘制或重新绘制前，必须具备 block diagram、powertree 和 pinlist，且三者的接口、电源域及引脚映射一致。缺少任何一项，或关键映射尚未确定，不进入原理图绘制。** 此时先整理缺失清单、收集资料和补全上述文件，再核对门槛。

| 前置资料 | 最低内容 |
|---|---|
| block diagram（系统框图） | 主控及功能模块、分图页边界、接口/总线名称、方向、通道或位宽、外部连接器。 |
| powertree（电源树） | 电源来源、转换与分配、输出电压和预算、上电/使能关系、模块电源域及地参考。 |
| pinlist（引脚分配表） | 主控及分图页器件位号、物理脚号、功能、总线成员/网络名、对端、I/O 电压域；记录复用、保留和未用脚处理。 |

文件格式可为表格、Markdown 或其他可编辑形式。文件存在不等于满足门槛：关键内容须可追溯且已核验；原理图中不以猜测代替缺失分配。

### 2.2 分图页电路依据

每个功能模块必须准备以下信息：

| 项目 | 必须记录的内容 |
|---|---|
| 设计依据 | datasheet/参考设计名称、版本、相关页码或链接。 |
| 器件选择 | 完整料号、封装、关键参数及装配状态；尚未选定的器件标为待确认。 |
| 引脚连接 | 器件位号、引脚号、功能、网络名、对端位号和引脚号。 |
| 电气条件 | 电源电压、I/O 电平、开漏上拉、时钟、复位、启动配置及未用脚要求。 |
| 物理约束 | 去耦位置、阻抗、长度、回流、隔离或机壳接地等需要落实到 PCB 的要求。 |

没有依据的引脚处理、器件值或拓扑应保留待确认标识，不得标称已验证。连接器和多通道保护器件必须使用真实引脚符号，并逐项核对封装焊盘号。

## 3. 页面与元器件布局

### 3.1 页面组织

- 先根据 block diagram 划分功能分图页，再安排主控页；每页有明确的芯片、功能和接口边界。
- 分图页通过命名总线与主控页连接。总线名、成员、位宽和方向来自 pinlist，页内展开到实际器件引脚。
- 数据、地址、控制、时钟和复位按功能分组；标量可作为命名接口组成员或独立层次端口，电源和地明确表达各自域。
- 优先采用软件支持的层次页接口/端口，并在父页连接主控和分图页；若软件以其他方式表达跨页总线，必须保留可核对的成员映射和页间引用。
- 总线线条只表示信号集合，不把各位电气短接；差分对保留独立 P/N 网络。普通文字和装饰线不视为连接。
- 分图页与主控页的接口定义必须双向一致，逐项核对物理脚号、位序、方向和电压域。
- 整理现有工程时，必须复用工程已有的原理图符号，默认保留符号外形、引脚位置、编号、名称、电气类型及原有多单元划分；用户明确要求调整符号分区时，按独立的器件库制作标准执行，并保持物理引脚身份和电气连接。新增器件无原有符号时建立对应真实引脚符号，并记录来源。
- 页面容量以可读性决定。文字拥挤或连线大量绕行时，扩大功能区或增加页面。
- 标题栏、页边框和页内标题周围必须预留空间，器件、连线和注释不得压入标题栏。

### 3.2 元器件摆放顺序

1. **先放主器件**：主芯片、连接器、输入与输出器件确定主要阅读方向。双向接口也应有明确的“控制器—接口处理—连接器”顺序。
2. **再放串联件**：串联电阻、耦合电容、磁珠、共模电感等沿真实信号或供电路径摆放。
3. **再放支路件**：上拉/下拉、偏置、滤波、反馈和测试点靠近其服务的节点。
4. **再放辅助组**：晶振及负载电容、复位、配置、去耦各成可辨认的小组，并注明所属器件或电源域。
5. **最后对齐**：同类通道相同朝向、同列对齐、间距一致；差分对相邻；功能区之间保留明显空白。

布局必须同时预留器件属性和网络标签空间。器件图形可按阅读需要调整引脚位置，但引脚号、电气类型和连接关系必须保持准确。原理图坐标用于表达关系，PCB 放置距离另行约束。

## 4. 布局完成后的布线规则

### 4.1 连线顺序与几何

1. 先连接电源、去耦、晶振、复位及配置等局部电路。
2. 再连接主信号和接口通路，串联件画在线上，支路从明确节点引出。
3. 最后安排网络标签、总线和跨页接口。

- 器件引脚、导线端点、连接点和标签锚点必须在兼容的电气网格上精确重合。
- 建议使用水平、垂直导线和直角转折；避免导线穿过符号本体、位号、参数或说明。
- 建议用 T 形分支减少四向交叉。需要连接的分支必须有明确连接点；不相连的交叉应易于辨认。
- 程序生成原理图时，建议在分支节点处分割主干线段，并导出网表验证，不能仅凭连接点图形判断已经连通。
- 必须检查串联器件两侧网络：器件既不能被旁路线短接，也不能有一端悬空。

### 4.2 信号组、标签与电源

| 对象 | 规则 |
|---|---|
| 差分对 | 正负线相邻、同向、线序一致；逐个核对芯片、串联件、保护器件和连接器的 P/N 映射。 |
| 总线 | 按功能和位号成组；明确位范围及展开后的成员名，逐位核对。 |
| 页内连接 | 局部短连接优先使用实线；远距离可使用作用范围明确的网络标签。 |
| 跨页连接 | 分图页与主控页通过命名总线/层次接口连接；全局标签按软件与项目约定用于明确的公共网络，不能替代总线成员映射检查。 |
| 电源与地 | 不同电压域、模拟/数字电源及特殊地使用明确名称；供电路径和去耦必须实际闭合。 |
| 未用引脚 | 按 datasheet 决定悬空、NC、上下拉或其他处理；不得为消除 ERC 提示随意接地或标 NC。 |

标签必须通过其锚点连接到导线或引脚。普通说明文字不具有电气连接作用。不得将双向、翻转选择或隔离接口简化成缺少必要控制的直接短接。

## 5. 器件标识与文字摆放

### 5.1 属性位置

| 器件/标识 | 默认位置 | 必须避免 |
|---|---|---|
| 芯片 U、连接器 J | 编号和型号位于符号上方，编号在上、型号在下，采用统一对齐方式。 | 压住顶部引脚、电源符号或功能标题。 |
| 水平 R/C/L | 编号、参数成两行，统一放在线路上方；必要时整组移至下方。 | 属性落在线上，或相邻器件的文字混在一起。 |
| 垂直 R/C/L | 编号和参数放右侧，编号在上、参数在下，同组文字列对齐。 | 压住相邻支路或地符号。 |
| 晶振 Y | 编号和频率/短型号放上方或右侧，与负载电容属性错开。 | 引脚和晶振连接被文字遮挡。 |
| 网络标签 | 锚点在线端或节点，文字沿清楚的阅读方向，同组标签对齐。 | 文字看似在线旁，锚点却悬空。 |
| 注释与测试点 | 靠近所属器件或功能组，保持明确对应关系。 | 注释跨越无关区域，或无法辨认服务对象。 |

### 5.2 标识内容

- 位号在整个工程内唯一，多单元芯片共用位号。已与 PCB/BOM 对应的位号应保持稳定；重新编号时必须同步对应关系。
- 元件值、精度、耐压、封装、完整订货号和装配状态使用对应属性字段。图面显示影响理解和选型的必要信息，长订货号可保留在属性/BOM 中。
- 数值与单位格式统一，例如 `49.9 Ω 1%`、`100 nF`、`25 MHz`。同一级文字使用一致字号。
- 文字尽量保持水平阅读；旋转器件后必须检查属性方向和重叠。
- 可选件使用 EDA 的 DNP/装配属性，并注明选配目的；属性与 BOM 一致。
- 属性过长时先移动文字、增加间距或扩展功能区，再考虑调整字号。

## 6. 建议的默认绘图参数

下列数值是可调整的起点，不是通用电气标准或参考 PDF 的测量值。

| 参数 | 建议起点 |
|---|---|
| 常规电气网格 | 1.27 mm（50 mil）；特殊符号需要更细网格时确保连接对象精确对齐。 |
| 位号、参数、网络名字高 | 1.27 mm，依打印效果调整；同级保持一致。 |
| 功能标题字高 | 2.0–2.5 mm。 |
| 线与文字的距离 | 保留明显可见间隙，以完整文字边界为准。 |
| 器件及通道间距 | 按网格重复；容纳最长属性和支路线后，再统一同组间距。 |

颜色用于辅助识别，不能代替连接点、标签、器件属性或装配状态。

## 7. 验证、迭代与交付门槛

### 7.1 电气验证

- 导出网表，核对关键器件的“引脚—网络—对端引脚”，重点检查供电、去耦、差分极性、时钟、复位、开漏上拉、启动配置和连接器屏蔽。
- 仅整理已有图纸的布局时，保留修改前网表，与修改后网表比较器件引脚所属网络；预期之外的增删、短接或断线必须修正。涉及电气修改时逐项记录修改依据。
- 运行 ERC，解决实际错误；合理的例外需记录原因和设计依据。不得批量忽略提示、增加无依据的电源标志或改变引脚类型来制造“通过”。
- 核对符号脚号、封装焊盘、完整料号及装配状态；导入 PCB 前完成对应关系检查。

### 7.2 图片验证

导出每页 PDF/图片，先检查整页结构，再放大检查局部：

- 功能区有清楚的阅读顺序，重复电路排列一致。
- 编号、参数、引脚号和网络名可读，无重叠、裁切或标题栏侵占。
- 导线转折、连接点、交叉和差分线序清楚，局部电路能够追踪。
- 空间用于分区和阅读；密集处通过重新摆放或拆页解决。

视觉检查不合格时回到布局阶段；连接检查不合格时回到引脚连接表和布线阶段。修改后重新验证受影响的网络并导出最新页面复检。

### 7.3 最终交付

交付可编辑原理图、相关符号/封装库、逐页 PDF/图片、关键连接核查记录和 ERC 结果。电气依据不足或存在未解决连接错误的页面必须标为待确认，不能标称投板验收通过。

## 8. 可直接复制到后续绘图任务的要求

> 请按《可复用的原理图绘制设计规则》绘制或整理原理图。先核验 block diagram、powertree、pinlist 齐备且一致，缺失时先补全、不进入绘制。按系统框图划分功能分图页，通过命名总线/层次接口与主控连接，逐成员核对引脚映射。再依据完整 datasheet 和参考设计建立电路连接表，按功能分区安排主器件、串联件、支路件及辅助电路。信号路径尽量从左到右，电源向上、地向下，重复通道保持一致。布局完成后连接局部电路和主信号，再安排作用范围正确的网络标签与跨页接口。统一位号、参数和型号的位置，保证文字与引脚及导线无重叠。导出网表核对关键连接并运行 ERC；仅整理布局时比较修改前后网络。逐页导出图片检查可读性，不合格则重新布局或布线，并复检到满足验收要求。交付可编辑文件、导出图和核查记录。

## 补充：无源晶振电路的统一绘制样式

依据用户提供的示例，无源晶振使用以下布局：

- 晶体竖直摆放，上方为 XI/晶振输入节点，下方为 XO/晶振输出节点。
- 两条信号线水平向右引出；两颗负载电容分别沿上、下信号线水平向左接地。
- 晶体与信号线的分支处标出连接点，位号与频率放在晶体右侧；负载电容位号和值统一放在上、下方。
- 预留一个可选反馈电阻，竖直放在晶体右侧，跨接 XI/XO。默认 DNP（不装），阻值根据芯片厂家资料确认。
- 反馈电阻与 XO 串联的驱动限制电阻是不同用途；若厂家要求串联电阻，按其参考设计另行处理。
- 外部反馈电阻并非每种芯片都需要。芯片已内置反馈电阻时，预留件保持不装；不得未经核对将可选件改成必装件。
