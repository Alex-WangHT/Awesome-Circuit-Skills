# 分图页：芯片外围小元件

适用于配置、复位、偏置、端接、滤波及反馈用 R/C/L；去耦和接口保护分别见同系列文档。

## 确认作用再摆放

先按 datasheet/参考设计确定每个元件服务的引脚、网络、数值、精度和装配状态，再安排位置。未用 GPIO、启动配置及内部上下拉不能仅凭名称推断。

| 用途 | 摆放与布线 |
|---|---|
| 串联电阻、耦合电容、磁珠 | 沿所属路径排列，两端网络明确；PCB 的靠近端另行注明。 |
| 上拉/下拉 | 贴近所属控制节点，上拉向电源、下拉向地；支路连接点明确。 |
| 启动配置 | 按对应配置脚成组，同类支路方向和间距一致，标注启动状态及可选装配。 |
| 复位 RC、滤波、偏置 | 靠近服务的引脚形成完整小电路，表达真实串并联关系；测试点靠近对应节点。 |
| 晶振及负载/反馈件 | 独立小组，采用总标准的晶振样式；参数和可选件按厂家要求。 |

## 排列与标识

- 主控/功能芯片相关元件归属于该器件区域，避免把所有电阻集中到远离服务对象的一角。
- 同类支路成行成列、等距排列，按信号位序或配置功能排序；不同用途之间留白并加简短标题。
- 水平元件的位号、参数两行放在线路上方；竖直元件放右侧，位号上、参数下，同组文字对齐。
- 标签靠近线端，标题靠近对应组；不让说明文字代替电气标签。可选元件使用 DNP/装配属性，说明用途。

## 检查

核对配置状态、极性、上下拉电源域、RC/偏置依据和装配组合；检查串联件未被短接、支路实际接入。导出网表与图片，检查连接及文字重叠，并向 PCB 交接需靠近芯片或端口的元件。
